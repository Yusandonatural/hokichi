# hokichi — 耕作放棄地を見つけ、地番と地主を特定し、自然栽培に切り替える

耕作放棄地（荒廃農地・遊休農地）を **探す → 地番を特定する → 地主を特定する → 借りる → 自然栽培に転換する**
までを、公的なデータと法定手続だけで一本につなぐための作業手順書とツール一式。

株式会社悠三堂（奈良県・自然栽培茶）の圃場拡大を想定した既定値で書いてあるが、
対象地域・作物・評価基準はすべて `data/config.json` で差し替えられる。

## なぜ手順書とツールなのか

「日本の耕作放棄地を探して、地主を特定する」は、ネット検索で答えが出る作業ではない。
実際には次の3つの層をまたぐ必要があり、それぞれ入口が違う。

| 層 | 得られるもの | 入口 | 氏名は載るか |
|---|---|---|---|
| ① 農地情報の公表データ | 所在・**地番**・地目・面積・遊休農地かどうか・所有者の意向 | eMAFF農地ナビ（誰でも無料） | **載らない** |
| ② 不動産登記 | **所有者の氏名・住所**、共有関係、相続の有無 | 登記情報提供サービス／法務局（有料・誰でも可） | 載る |
| ③ 現場と窓口 | 実際に貸す気があるか、水利・道・獣害、地域計画上の位置づけ | 農業委員会・農地バンク・自治会 | — |

①は機械で絞り込める。②は①で確定した地番がないと引けない。③は人に会うしかない。
このリポジトリは **①を自動化し、②③を定型作業に落とす** ことを目的とする。

## いちばん短い使い方

```bash
# 1. eMAFF農地ナビ (https://map.maff.go.jp/) で対象市町村を表示し、CSVをダウンロード
# 2. 候補地を機械的に絞り込む
python3 tools/hokichi.py rank data/sample/emaff_sample.csv --out out

# 3. 出力を確認
#    out/shortlist.md        … 点数順の候補地一覧
#    out/parcels_to_query.csv … 登記を引くための地番リスト（②の入力）
#    out/survey/*.md          … 現地調査シート（③の持ち物）
```

そのあとは `docs/00-全体フロー.md` の順に進める。

## 前提と限界（先に読むこと）

- **このリポジトリは地主の氏名を出力しない。** 氏名・住所は不動産登記にしかなく、
  取得には法務局または登記情報提供サービスへの請求（有料・本人申請）が要る。
  ツールは「どの地番を請求すべきか」までを自動化し、請求は人間が行う。
- **農地台帳の公表事項に個人名は含まれない**（農地法52条の3）。
  eMAFF農地ナビをいくら見ても地主は分からない。ここを混同すると調査が止まる。
- **耕作放棄地は「空いている土地」ではない。** すべてに所有者がいて、
  農地の権利移動には農地法3条の許可（または農地バンク経由の手続）が必要になる。
  無断で耕すことはできない。
- 取得した氏名・住所は個人情報である。`docs/03-地主を特定する.md` の取り扱い原則に従うこと。
