# 06 制度と補助金

**予算事業は年度ごとに名称・要件・予算額が変わる。**
ここに書いたものは制度の「型」を理解するための骨格であり、
実際の申請前に必ず市町村の農政担当課と県の担当課で最新の要綱を確認すること。
`99-出典.md` の一次情報リンクから当年度のページに入る。

## 荒廃農地の再生に使えるもの

| 制度 | 内容 | 窓口 |
|---|---|---|
| **農山漁村振興交付金（最適土地利用総合対策）** | 地域ぐるみの話し合いによる土地利用構想の策定、荒廃農地の再生作業、簡易な基盤整備、粗放的利用の導入 | 市町村 → 県 |
| **農地利用効率化等支援交付金** | 農業用機械・施設の整備（上限・補助率は年度要綱による） | 市町村 |
| **中山間地域等直接支払制度** | 集落協定に基づく農用地の維持。荒廃農地の発生防止と再生に使える | 市町村 |
| **多面的機能支払交付金** | 農地・水路・農道の共同管理活動 | 活動組織／市町村 |
| 県・市町村の単独事業 | 新規就農支援、獣害柵、移住＋就農のパッケージ など | 県・市町村 |

※ かつての「耕作放棄地再生利用緊急対策交付金」は終了し、
上記の交付金群に再編されている。古い記事が残っているので名称だけで検索しないこと。

## 新規就農・経営に使えるもの

| 制度 | 内容 |
|---|---|
| 新規就農者育成総合対策（経営開始資金・経営発展支援事業） | 就農初期の生活費支援と機械・施設の導入支援 |
| 青年等就農計画（認定新規就農者） | 認定を受けると資金・税制で有利。**農地法3条の交渉でも信用材料になる** |
| 農業次世代人材投資資金の後継制度 | 年度ごとに要件が変わる。年齢制限に注意 |
| 日本政策金融公庫（青年等就農資金・スーパーL資金） | 無利子・長期の制度融資 |

## 有機農業に使えるもの

| 制度 | 内容 |
|---|---|
| **みどりの食料システム戦略／有機農業推進** | 有機農業の団地化・産地づくりへの支援。**オーガニックビレッジ**に取り組む市町村なら特に厚い |
| 環境保全型農業直接支払交付金 | 有機農業（化学肥料・化学合成農薬を使用しない取組）に対する支払い |
| 有機JAS認証取得支援 | 認証費用・コンサル費用の補助（県・市町村単独が多い） |

**オーガニックビレッジ宣言をしている市町村は、地域選定の強い材料になる。**
自然栽培への理解が行政側に既にあり、農地のあっせんでも配慮が期待できる。
対象地域を決める段階（Phase 0）で、候補市町村が宣言済みかを確認すること。

## 税制

| 項目 | 内容 |
|---|---|
| 遊休農地の課税強化 | 農業委員会が農地中間管理機構との協議を勧告した農用地区域内の遊休農地は、固定資産税評価で0.55を乗じない扱いとなり、結果として**約1.8倍**になる |
| 機構への貸付けによる軽減 | 農地バンクに一定期間貸し付けた農地は固定資産税が軽減される特例がある |

この2つは **地主を動かす材料**になる。
「放置すると税が上がる／機構に貸すと下がる」は、借受交渉で地主にとっての実利になる。
ただし自分から税の話を切り出すと圧力に見えるので、
**農業委員会から説明してもらう**のが筋。

## 申請の実務

- [ ] **着工前に申請する**（事後申請は原則認められない）
- [ ] 年度の締切が早い（前年度の秋〜冬に要望調査があることが多い）
- [ ] 補助を受けた施設・機械には処分制限期間がある
- [ ] 実績報告と証拠書類（見積・契約・請求・領収・写真）が要る。**着工前・中間・完了の写真は必須**
- [ ] 複数制度の併用可否を先に確認する（同一経費の重複は不可）
