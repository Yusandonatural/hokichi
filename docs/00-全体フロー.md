# 00 全体フロー — 着手から自然栽培の作付けまで

所要期間の目安は、順調に進んで **着手から作付けまで 6〜12か月**。
相続未登記や所有者不明が絡むと、裁定まで含めて 1〜2年を見る。

```
[Phase 0] 対象地域を決める                    … 1週間
     ↓
[Phase 1] 机上調査：候補地を絞る               … 2〜4週間   ← tools/hokichi.py
     ↓
[Phase 2] 地番を確定する                       … 1〜2週間
     ↓
[Phase 3] 現地調査                             … 2〜4週間   ← templates/現地調査シート.md
     ↓
[Phase 4] 地主を特定する                       … 2〜4週間   ← 登記／農業委員会
     ↓
[Phase 5] 交渉・権利設定（農地法3条 or 農地バンク） … 2〜6か月
     ↓
[Phase 6] 再生作業と自然栽培への転換            … 3年（有機JAS表示まで）
```

Phase 3 と Phase 4 は並行してよい。ただし **Phase 4 より先に地主へ直接接触しない**
（窓口を飛ばすと地域での信用を落とす。詳細は `03-地主を特定する.md`）。

---

## Phase 0 — 対象地域を決める

自然栽培は「隣で何をしているか」に成果が左右される。地域選定の段階で勝負がつく。

優先する条件:

- [ ] 谷筋の最上流、または山際で **上流側に慣行栽培圃場がない**（水系からの流入を断てる）
- [ ] 周囲が山林・原野・他の遊休農地に囲まれている（空中散布・ドリフトの遮蔽）
- [ ] 中山間地域等直接支払制度の協定エリア内（地域ぐるみの話し合いの場がある）
- [ ] 市町村の **地域計画（目標地図）** が策定済み、または策定中
      → 誰がどの農地を使う予定かが一筆ごとに決まっている。ここに入らないと権利設定が進まない
- [ ] 通える距離（再生作業と草管理は頻度が命。片道1時間を超えると続かない）

決めたら `data/config.json` の `target` に市町村コードを書く。

## Phase 1 — 机上調査：候補地を絞る

1. [ ] eMAFF農地ナビ（https://map.maff.go.jp/）で対象市町村を表示
2. [ ] 遊休農地・低利用農地の表示をONにして範囲を確認
3. [ ] 公表データ（CSV）をダウンロード → `data/` に置く
4. [ ] `python3 tools/hokichi.py rank <csv> --out out` を実行
5. [ ] `out/shortlist.md` の上位20筆前後を目視で確認、明らかな外れを落とす

→ 詳細は `01-耕作放棄地を探す.md`

## Phase 2 — 地番を確定する

6. [ ] `out/parcels_to_query.csv` の「所在・地番」表記を正規化（大字・字・枝番）
7. [ ] 公図（法務局／登記情報提供サービス 地図情報）で隣接関係と形状を確認
8. [ ] 隣接する遊休農地をまとめて **団地として扱えるか** を判断（1筆だけ借りても管理が破綻しやすい）

→ 詳細は `02-地番を特定する.md`

## Phase 3 — 現地調査

9. [ ] `templates/現地調査シート.md` を候補数だけ印刷（`tools/hokichi.py` が候補別に生成する）
10. [ ] 荒廃度（A分類＝再生可能／B分類＝復元困難）を自分の目で判定
11. [ ] 進入路・車の入れ方・水利・電気・獣害柵・法面の有無を記録
12. [ ] 周辺圃場の栽培方法とドリフトリスクを記録（緩衝帯が何m取れるか）
13. [ ] 土壌サンプルを採取（Phase 6 のベースライン。転換の起点を数字で押さえる）

## Phase 4 — 地主を特定する

14. [ ] 地番ごとに登記事項証明書（全部事項）を取得 → 所有者の氏名・住所
15. [ ] 相続登記が済んでいるか確認（被相続人名義のままなら相続未登記農地）
16. [ ] 共有名義なら共有者の数と持分を確認
17. [ ] **農業委員会に相談**し、意向調査の結果（貸す意思があるか）を確認
18. [ ] 接触は原則 農業委員会・農地バンク・自治会長を経由

→ 詳細は `03-地主を特定する.md`

## Phase 5 — 交渉・権利設定

19. [ ] 借りるか買うかを決める（初回は **借りる** を強く推奨。再生費用の回収前に離農リスクを負わない）
20. [ ] 賃料・期間・再生作業の費用負担・原状回復の要否を詰める
      → 荒廃農地は「無償〜反あたり数千円／年」が現実的な相場帯。再生費用の負担で調整する
21. [ ] 経路を選ぶ
      - 農地バンク（農地中間管理機構）経由 … 地域計画に沿う。地主の安心感が高い。奈良県は「なら担い手・農地サポートセンター」
      - 農地法3条許可 … 当事者間で直接。下限面積要件は2023年4月に廃止済
      - 所有者不明・共有者不明 … 農業委員会の探索・公示（2か月）→ 知事裁定で農地バンクに利用権（最長40年）
22. [ ] 許可・公告が出るまで作業を始めない

→ 詳細は `04-交渉と権利設定.md`

## Phase 6 — 再生と自然栽培への転換

23. [ ] 再生作業（刈払い → 抜根 → 残材処理 → 耕起または不耕起の選択）
24. [ ] **転換開始日を記録する**（有機JASの起算点。ここを曖昧にすると3年やり直し）
25. [ ] 圃場ごとに栽培管理記録を開始（資材・作業・隣接地の散布状況）
26. [ ] 緩衝帯・生垣・防風林を先に作る
27. [ ] 1〜2年目は緑肥・草生で土をつくる。収量を期待しない期間として予算を組む
28. [ ] 3年目以降、多年生作物（茶）は最初の収穫前3年以上の有機的管理で有機JAS表示が可能

→ 詳細は `05-自然栽培への転換.md`

## 撤退判断の基準

次のいずれかに当たったら、その候補は落として次へ行く。粘る価値はない。

- 荒廃農地B分類（森林化・復元しても継続利用が見込めない）
- 上流側または風上に慣行栽培の水田・果樹園があり、緩衝帯が10m未満しか取れない
- 共有者が10名を超え、かつ農業委員会が探索・公示に乗り気でない
- 進入路が他人の私有地で、通行承諾が取れない
- 地域計画の目標地図で他の担い手に割り当て済み
