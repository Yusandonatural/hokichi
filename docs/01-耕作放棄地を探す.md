# 01 耕作放棄地を探す

## まず用語を揃える

現場・統計・法律で言葉がずれている。ここを混同すると窓口で話が通じない。

| 用語 | 定義 | 誰が決めるか |
|---|---|---|
| **耕作放棄地** | 過去1年以上作付けせず、数年の間に再び作付けする意思のない土地 | **農家の自己申告**（農林業センサスの主観ベース。2020年センサスを最後に調査項目としては整理された） |
| **荒廃農地** | 現に耕作されておらず、耕作の放棄により荒廃し、通常の農作業では作物の栽培が客観的に不可能な農地 | 農業委員会の**現地調査**（客観ベース） |
| ├ **A分類** | 抜根・整地・区画整理・客土等により**再生すれば耕作可能**と見込まれる | 同上 |
| └ **B分類** | 森林の様相を呈するなど**農地への復元が著しく困難**、または復元しても継続利用が見込めない | 同上 |
| **遊休農地（1号）** | 現に耕作されておらず、引き続き耕作されないと見込まれる農地 | 農地法30条の利用状況調査 |
| **遊休農地（2号）** | 周辺地域の農地に比べ**利用の程度が著しく劣っている**農地 | 同上 |

**探すべきは「荒廃農地A分類」または「遊休農地」で、かつ農振農用地区域内のもの。**
B分類は再生費用が回収できない。区域外は転用圧力で長期の安定利用がしにくい。

自然栽培の観点ではもう一つ効く事実がある。荒廃農地は
**数年間、農薬も化学肥料も入っていない**。転換期間の起算で有利になりうるので、
「いつから耕作されていないか」（利用状況調査日と遊休農地の判定履歴）は必ず押さえる。

## データ源

### 1. eMAFF農地ナビ（本命）
https://map.maff.go.jp/

各農業委員会が農地法52条の3に基づいて公表する**農地台帳の公表事項と地図**を、
全国横断で閲覧・ダウンロードできる。登録不要・無料。

得られる主な項目（自治体により欠損あり）:

- 市区町村コード / 所在・**地番** / 地目 / 面積
- 農振法区分（農用地区域内かどうか）/ 都市計画法区分
- **遊休農地かどうか** / 利用状況調査日
- **所有者等の確知の状況**（＝所有者不明農地かどうかの手がかり）
- **所有者の農地に関する意向** / 遊休農地の所有者等の意向 / 利用意向調査日
- 農地中間管理権の状況 / 権利の種類 / 存続期間始期

**含まれないもの: 所有者の氏名・住所。** これは登記でしか取れない（→ `03`）。

### 2. 農業委員会の窓口（必須）
公表データは更新が遅れることがある。最新の利用状況調査・利用意向調査の結果は窓口にある。
またここで「そもそもこの地域で新規の借り手を探しているか」が分かる。
`templates/農業委員会_照会文.md` を使う。

### 3. 農地バンク（農地中間管理機構）
借受希望者として登録しておくと、機構に集まった出し手の情報とマッチングされる。
相談・登録は無料。奈良県は **公益財団法人 なら担い手・農地サポートセンター**（橿原市畝傍町53）。

### 4. 地域計画・目標地図
2023年4月から「人・農地プラン」が「地域計画」として法定化され、
**一筆ごとに将来の耕作者を定めた目標地図**の作成が義務づけられた。
ここに自分が位置づけられるかどうかが、実質的な可否を決める。市町村の農政担当課で閲覧する。

### 5. 統計で地域を当たりを付ける
- 農林水産省「荒廃農地の発生・解消状況に関する調査結果」（市町村別）
- e-Stat / わがマチ・わがムラ（https://www.machimura.maff.go.jp/）
  市町村別の経営耕地面積・担い手数の推移から、10年後に農地が余る地域を読む。

### 6. 空き家バンク・移住定住窓口
農地付き空き家として出てくることがある。農地単独より条件交渉が早い場合がある。

## 絞り込みの考え方（ツールの採点基準）

`tools/hokichi.py` は以下を重み付けして採点する。重みは `data/config.json` で変更できる。

| 観点 | 加点 | 減点 |
|---|---|---|
| 遊休農地フラグ | 遊休農地・低利用と判定済み | — |
| 所有者の意向 | 「貸したい」「農地バンクに預けたい」 | 「自ら耕作する」 |
| 農振法区分 | 農用地区域内（青地） | 区域外 |
| 面積 | 10a〜50a（1筆で機械が入り、かつ手が回る） | 極端に小さい／大きい |
| 地目 | 畑・樹園地（茶は畑地。水田は転換に排水工事が要る） | 田 |
| **団地性** | 隣接・連続地番の遊休農地がまとまっている | 孤立した1筆 |
| 所有者等の確知 | 確知済（交渉が早い） | 不明（手続が長期化。ただし裁定ルートあり） |
| 中間管理権 | 既に機構が権利を持つ（話が早い） | — |

**団地性を重視する理由**: 孤立した1筆を借りても、周囲が荒れたままでは
草の種と獣が絶えず入ってくる。自然栽培では除草剤で押さえ込めないので、
面で押さえるか、境界に構造物（緩衝帯・生垣）を作るかの二択になる。
連続する遊休農地をまとめて借りるほうが、結果的に労力が減る。

## 手順

```bash
# 1. eMAFF農地ナビで対象市町村を表示し、CSVをダウンロード
# 2. 文字コードは自動判定される（UTF-8 / Shift_JIS 両対応）
python3 tools/hokichi.py rank data/sample/emaff_sample.csv --out out

# 列名が自治体独自で認識されない場合は、まず中身を確認
python3 tools/hokichi.py inspect data/sample/emaff_sample.csv

# マッピングを明示する
python3 tools/hokichi.py rank <csv> --map data/column_map.json --out out
```

出力:

- `out/shortlist.md` — 点数順の候補地一覧（団地ごとにグループ化）
- `out/candidates.csv` — 同じ内容のCSV
- `out/parcels_to_query.csv` — **登記を引くための地番リスト**（→ `03`）
- `out/survey/*.md` — 候補ごとの現地調査シート（→ Phase 3）

→ 次は `02-地番を特定する.md`
