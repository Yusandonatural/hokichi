# 02 地番を特定する

地番は登記を引くための鍵であり、**住所（住居表示）とは別物**。
農地には住居表示がないことがほとんどなので、実務上は地番しか手がかりがない。

## 地番の構造

```
奈良県 宇陀市 大宇陀 迫間 字 ○○  123番4
└県──┘ └市──┘ └大字─┘└小字─┘ └地番┘
                                     └枝番
```

- 「123-4」「123番4」「123番地4」は同じものを指す。表記ゆれを正規化してから照合する。
- 枝番は分筆でできる。**枝番が多い地番の周りは分筆が進んでおり、相続が絡んでいる可能性が高い**。
- 同じ大字の中で地番が連続していれば、現地でも隣接していることが多い（ただし必ずではない。公図で確認）。

`tools/hokichi.py` は `所在・地番` を「市区町村 / 大字 / 字 / 地番本番 / 枝番」に分解し、
本番の連続性で団地候補をクラスタリングする。

## 手順

### 1. eMAFF農地ナビで地番を拾う
地図上で区画をクリックすると、その筆の所在・地番・地目・面積・遊休農地かどうかが表示される。
一覧で欲しい場合は表示範囲のCSVをダウンロードする。

### 2. 公図で隣接関係を確認する
地番だけでは形状と接道が分からない。公図（地図または地図に準ずる図面）を見る。

- **登記情報提供サービス**（https://www1.touki.or.jp/）
  「地図及び図面が記録されたファイルの情報」= 360円（2026年4月1日改定後）
  オンラインで即時、PDFで取得できる。一時利用ならクレジットカード決済で登録直後に使える。
- **法務局の窓口**：地図の写しの交付。相談しながら進めたいときはこちら。

公図で必ず見るもの:

- [ ] 進入路になる公道・里道（赤線）・水路（青線）に接しているか
- [ ] 接していない場合、誰の土地を通るか（通行承諾の相手が増える＝難度が上がる）
- [ ] 隣接筆の地番（→ 隣地の所有者も後で調べる。境界と緩衝帯の交渉相手になる）
- [ ] 縄伸び・縄縮みの気配（公図の形と航空写真の形が大きく違う場合は要注意）

### 3. 航空写真・地理院地図と重ねる
- 地理院地図（https://maps.gsi.go.jp/）で等高線・傾斜・水系を見る
- 過去の空中写真で **いつから耕作されていないか** を推定する
  （1970年代〜現在の空中写真が閲覧できる。荒れ始めた時期＝無投入期間の目安になる）

### 4. 表記を正規化して照合リストを作る

```bash
python3 tools/hokichi.py parcels out/candidates.csv --out out
# → out/parcels_to_query.csv
#   市区町村, 大字, 字, 地番, 正規化地番, 面積, 用途, 備考
```

このCSVがそのまま Phase 4（登記請求）の入力になる。

## よくある詰まりどころ

| 症状 | 原因 | 対処 |
|---|---|---|
| eMAFF農地ナビに区画が出てこない | 農地台帳に未登載、または既に非農地判断されている | 農業委員会に照会。非農地判断済なら農地法の許可は不要だが、農地としての支援制度も使えない |
| 地番で登記が引けない | 大字・字の表記ゆれ、合併前の旧町名 | 法務局で地番検索（ブルーマップ／地番区域）を確認 |
| 公図と現地が合わない | 地図に準ずる図面（旧公図）で精度が低い | 現地立会いを前提にする。境界未確定のまま賃借はできるが、購入は避ける |
| 1筆が異様に広い／細長い | 棚田や段畑が1筆にまとまっている | 現地で段数と法面の量を数える。法面管理は面積に比例しない負担になる |
