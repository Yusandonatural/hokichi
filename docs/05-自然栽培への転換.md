# 05 自然栽培への転換

自然栽培（無農薬・無化学肥料、原則として無施肥）へ切り替える工程。
荒廃農地は **すでに数年〜数十年、何も投入されていない** という点で、
慣行圃場からの転換より有利な出発点にある。その利点を書類で証明できる形にしておく。

## 工程

```
年0  権利設定 → 現況記録 → 土壌サンプル採取 → 再生作業 → 転換開始日の確定
年1  緑肥・草生で土をつくる。緩衝帯の造成。収量は期待しない
年2  試験的な作付け。「転換期間中有機農産物」の表示が可能になる（一年生）
年3  多年生作物（茶）は最初の収穫前3年以上の有機的管理で「有機農産物」表示が可能
```

## 年0：着手前にやること（ここを飛ばすと3年やり直し）

### 1. 現況を証拠として残す

- [ ] 四隅と中央から写真（日付入り）。ドローンがあれば真上からも
- [ ] 荒廃の程度、植生（ススキ／クズ／竹／low木／実生の樹木）を記録
- [ ] **過去の空中写真**（地理院地図）で、いつから耕作されていないかを推定し印刷して保存
- [ ] 農業委員会の利用状況調査で**いつから遊休農地と判定されているか**を照会し、書面でもらう
      → これが「使用禁止資材が使われていない期間」の客観的な裏付けになる

### 2. 土壌サンプルを採取する

転換の起点を数字で押さえる。後年の変化を語るための基準線になる。

- [ ] 圃場を3〜5区に分け、各区5点以上の複合サンプル（深さ0〜15cm）
- [ ] 分析項目：pH、EC、CEC、腐植、可給態リン酸、交換性塩基（CaO/MgO/K2O）、塩基飽和度
- [ ] 残留農薬分析は必須ではないが、**慣行圃場からの転換や履歴不明の場合は一度やる価値がある**
- [ ] 分析結果は圃場ごとにファイルして保管

### 3. 再生作業

| 作業 | 判断 |
|---|---|
| 刈払い | 全面。刈った草は搬出せず圃場に戻す（有機物の持ち出しをしない） |
| 抜根 | 樹木・竹は根まで。竹は地下茎を除かないと3年戦い続けることになる |
| 残材処理 | 野焼きは自治体の条例と近隣の了解を確認。チップ化して戻すほうがよい |
| 耕起 | **1回目だけは起こす**判断が現実的。以後は不耕起／浅耕へ移行 |
| 排水 | 田から畑への転換は明渠・暗渠が要る。茶は停滞水に弱い |
| 石礫除去 | 機械作業の可否を決める |
| 獣害柵 | **再生作業と同時に。** 後から作ると1年目の作物を全部やられる |

### 4. 転換開始日を確定し、記録を開始する

**転換開始日＝有機的管理を開始した日。** この日付から起算する。
以後、圃場ごとに次を記録し続ける（有機JASを取らない場合でも、取引先への説明資料になる）。

- 作業日誌（日付・作業内容・使用機械）
- 投入資材の記録（自然栽培なら「投入なし」を記録し続けることに意味がある）
- **隣接圃場の散布状況**（いつ・何を・どの方向の風で）
- 種苗の出所（自家採種か、購入種苗か。購入なら化学処理の有無）

## ドリフト（飛散）対策

自然栽培の最大の技術的リスクは、自分の管理外から来る。

| 経路 | 対策 |
|---|---|
| 空中散布・隣接圃場からの飛散 | **緩衝帯**を取る。生垣・防風林・ソルゴー等の障壁作物。風上側を厚く |
| 用水路からの流入 | 上流側に慣行圃場がある水系を使わない。独立水源（沢・井戸・雨水）を確保する |
| 表面流去水 | 法面の上手から入る水を明渠で振る |
| 農道からの飛散（除草剤） | 道路管理者・自治会に事前に申し入れ。標識を立てる |
| 汚染された客土 | **客土は履歴が追えるものだけ。** 安易に土を入れない |

緩衝帯の幅は、有機JASでは「周辺から使用禁止資材が飛来・流入しないよう
必要な措置を講じる」とされ、具体的な数値は定められていない。
実務的には **風上側10m以上、生垣があれば5m程度** を目安に、
隣接者と申し合わせて散布時の連絡体制をつくるほうが確実。

## 有機JASを取るかどうか

自然栽培は有機JASより厳しい実践（無施肥）だが、**名乗るには認証が要る**のは有機JASのほう。
「有機」「オーガニック」と表示するには有機JAS認証が必須。
「自然栽培」「農薬・化学肥料不使用」の表示には認証は不要（ただし表示の裏付けは必要）。

転換期間（有機JAS）:

| 作物 | 必要な有機的管理期間 |
|---|---|
| 一年生（野菜等） | 最初の**播種・植付前**に2年以上 |
| **多年生（茶・果樹）** | 最初の**収穫前**に3年以上 |
| 2年以上使用禁止資材が使われていない**休耕地** | 有機的管理の開始から**1年以上**で「有機農産物」として格付可能 |

最後の行が荒廃農地の最大の利点。
**「2年以上放置されていた」ことを証明できれば、転換期間を大幅に短縮できる。**
だから年0の「1. 現況を証拠として残す」が重要になる。
農業委員会の利用状況調査記録、過去の空中写真、前所有者・近隣の証言（書面化）を揃える。

なお、転換途中でも一年生は2年目から「転換期間中有機農産物」と表示できる。

## 1〜3年目の土づくり

自然栽培は「何もしない」ではなく「持ち出さず、壊さない」管理。

- **草は敵ではないが、競合は管理する** — 刈って敷く。根は残す。抜かない
- **緑肥** — マメ科（ヘアリーベッチ、クロタラリア）＋イネ科の混播。すき込みではなく敷草でもよい
- **不耕起へ移行** — 1年目の1回で耕盤をほぐしたら、以後は踏圧を避けて構造を育てる
- **排水** — 自然栽培でうまくいかない圃場の多くは肥料でなく水の問題
- **茶の場合** — 定植は10〜11月または3月。幼木期3〜4年は収穫しない前提で計画する

## 収支の考え方

3年間ほぼ収入がない前提で予算を組む。反あたりの初期費用の目安:

| 項目 | 目安 |
|---|---|
| 再生作業（刈払い・抜根・整地） | 10〜30万円／10a（B分類に近いほど高い） |
| 獣害柵 | 5〜15万円／10a |
| 土壌分析 | 5千〜2万円／点 |
| 苗（茶） | 20〜40万円／10a |
| 緩衝帯・防風 | 5〜20万円／10a |
