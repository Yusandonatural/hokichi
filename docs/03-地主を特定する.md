# 03 地主を特定する

## 大原則

**農地台帳の公表事項（eMAFF農地ナビ）に所有者の氏名は含まれない。**
農地法52条の3に基づく公表は、所在・地番・地目・面積・意向などに限られる。
氏名・住所は **不動産登記** にしかない。

不動産登記は誰でも請求できる公開情報で、農地の借受交渉のために所有者を調べるのは
正当な利用目的である。ただし取得するのは実在する個人の氏名と住所であり、
個人情報として適正に扱う義務が生じる。本書の末尾の取り扱い原則を必ず読むこと。

## ルートは2つある。原則は B → A の順

### ルートA：登記から直接たどる（事実確認）
### ルートB：農業委員会・農地バンクを通す（接触経路）

登記で氏名を知ること自体は自由だが、**それをもって直接自宅を訪ねるのは悪手**。
農地の貸し借りは地域の合意で動いており、窓口や自治会を飛ばして接触した新参者は
そこで信用を失う。**先に窓口に行き、窓口から話を通してもらう。**
登記調査は「窓口で話を進めるために自分が事実を把握しておく」ために行う。

---

## ルートA：登記事項証明書で所有者を確定する

### A-1. どちらで取るか

| 方法 | 費用 | 法的効力 | 使いどころ |
|---|---|---|---|
| **登記情報提供サービス**（オンライン） | 全部事項 **330円**（2026年4月1日改定後）／所有者事項 140円／図面 360円 | 証明書ではない（確認用） | **調査段階はこれ。** 数十筆を一気に確認できる |
| **登記事項証明書**（法務局・窓口／郵送） | 1通 600円 | 証明書として使える | 農地法3条の申請など、提出が必要なとき |
| オンライン請求＋郵送受取 | 1通 500円前後 | 証明書 | 枚数が多く急がないとき |

調査は全部事項330円で回し、申請書類に添付する段になってから証明書を取る。
所有者名だけ速く知りたいなら「所有者事項」140円でもよいが、
**共有・抵当・相続の有無まで見たいなら全部事項**を取る。

### A-2. 全部事項のどこを読むか

```
表題部  … 所在・地番・地目・地積。 地目が「畑」「田」なら農地法の対象
権利部（甲区） … 所有権。 ここに所有者の氏名・住所
権利部（乙区） … 所有権以外（抵当権・地上権・賃借権など）
```

読み取るべき状態:

| 甲区の状態 | 意味 | 次の一手 |
|---|---|---|
| 個人1名、最近の登記 | 通常の単独所有 | 窓口経由で交渉（→ ルートB） |
| 個人1名、登記原因が数十年前 | **相続未登記の可能性が高い**。名義人が既に故人 | 農業委員会へ。相続人の一人と交渉、または探索・公示ルート（→ `04`） |
| 複数名の共有 | 共有農地。全員の同意が要る | 持分と人数を確認。過半でよい場合・全員必要な場合がある |
| 「〇〇外3名」等 | 共有で一部の記載が省略 | 共同人名票を確認 |
| 法人・財産区・生産森林組合 | 集落の共有地由来 | 自治会・水利組合が実質的な窓口 |
| 乙区に抵当権 | 金融機関の担保 | 賃借は可能だが、購入なら抹消の確認が必須 |

2024年4月1日から**相続登記の申請が義務化**され（取得を知った日から3年以内、
正当な理由なく怠ると10万円以下の過料）、相続人申告登記という簡易な手段も設けられた。
それでも過去分の相続未登記農地は大量に残っている。
**「名義人がとうに亡くなっている」は想定内として動く。**

### A-3. 住所が古い場合

登記上の住所は移転していても更新されないことが多い。手紙が返ってくる前提で考える。
住民票の除票・戸籍の附票は、正当な理由の疎明が要る（第三者請求）。
ここに踏み込む前に、必ずルートBを試す。農業委員会は農地台帳で連絡先を把握していることが多く、
**そちらのほうが速く、角が立たない。**

---

## ルートB：農業委員会・農地バンクを通す（推奨される接触経路）

### B-1. 農業委員会に行く

持っていくもの:

- `out/parcels_to_query.csv`（候補の地番リスト）
- `templates/農業委員会_照会文.md` に記入したもの
- 自分の営農計画（面積・作物・機械・労働力・販路）
- 自然栽培でやることを一枚で説明できる資料

聞くこと:

- [ ] この地番は**利用状況調査で遊休農地と判定されているか**（1号／2号の別）
- [ ] **利用意向調査**に対する所有者の回答は何か（自ら耕作／貸したい／機構に預けたい）
- [ ] 所有者への連絡は可能か。**委員会から打診してもらえるか**
- [ ] 相続未登記か、所有者不明の扱いか
- [ ] **地域計画（目標地図）**でこの筆はどう位置づけられているか
- [ ] 地元の農会長・水利組合長は誰か（実質的な承認者）

農業委員会は毎年1回、農地法30条の利用状況調査を行い、遊休農地には利用意向調査をする。
**「貸したい」と回答済みの筆は交渉が一気に速い。** 最優先で当たる。

### B-2. 農地バンクに借受希望者として登録する

奈良県：公益財団法人 なら担い手・農地サポートセンター（橿原市畝傍町53）
相談・登録は無料。機構経由なら賃料の支払い・契約管理も機構が間に立つため、
地主側の心理的ハードルが大きく下がる。

### B-3. 自治会・水利組合に挨拶する

法的には不要。実務上は必須。水利権と農道の使用は集落の合意で動いている。
**自然栽培は「草を生やす農法」に見えるため、事前説明なしに始めると必ず揉める。**
何を、なぜ、どう管理するのかを先に説明し、畦畔の草刈り回数だけは
地域の標準に合わせると約束しておく。

## 所有者が見つからない場合

すべての相続人を追う必要はない。制度がある。

1. 農業委員会が**探索**（登記簿・住民票・戸籍等で可能な範囲）
2. 見つからなければ **公示（2か月）**
3. 公示から2か月以内に所有者等からの申出がなければ、農地法41条に基づき農地中間管理機構へ通知
4. 機構が都道府県知事に**裁定**を申請 → 知事の裁定・公告
5. 機構に**最長40年**の利用権が設定され、そこから担い手へ転貸される

つまり **借り手（あなた）が手を挙げることが、手続の起点になる。**
所有者不明だから諦める、ではなく、農業委員会に「この筆を借りたい」と申し出る。
詳細は `04-交渉と権利設定.md`。

## 取得した個人情報の取り扱い原則

登記から得た氏名・住所は、公開情報であっても個人情報である。以下を守る。

1. **目的を限定する** — 当該農地の借受交渉、および農地法・基盤強化促進法の手続に限る。
2. **共有しない** — リポジトリ・共有ドライブ・チャット・SNSに氏名や住所を書かない。
   本リポジトリは氏名を出力しない設計であり、`out/` は `.gitignore` 済み。
   手書き・紙の調査票も施錠管理する。
3. **直接接触は窓口経由を原則とする** — 突然の訪問・電話はしない。
   やむを得ず直接連絡する場合も、まず書面（`templates/地主宛_手紙.md`）で、
   断る自由を明示して送る。
4. **断られたら終わり** — 再交渉は1回まで。繰り返さない。
5. **交渉が終わったら消す** — 不成立になった筆の個人情報は保持しない。
6. **名寄せ・リスト化をしない** — 「この地域の地主一覧」を作らない。
   必要なのは交渉中の数筆だけであり、それ以上は目的外。
