# 04 交渉と権利設定

**農地は許可なく権利移動できない。** 無断で耕せば不法行為であり、
農地法違反（3年以下の懲役または300万円以下の罰金等）の対象にもなりうる。
どのルートを通るかを先に決める。

## 3つのルート

| | ①農地バンク経由 | ②農地法3条 | ③所有者不明・裁定 |
|---|---|---|---|
| 根拠 | 農業経営基盤強化促進法 | 農地法3条 | 農地法41条 ほか |
| 相手 | 農地中間管理機構 | 地主本人 | 機構（知事裁定） |
| 地主の同意 | 必要（機構へ貸す形） | 必要 | **不要**（探索・公示を経る） |
| 期間 | 促進計画の認可・公告まで2〜6か月 | 毎月の総会に諮る（1〜2か月） | 公示2か月＋裁定。半年〜1年 |
| 賃料 | 機構が集金・支払い | 当事者間 | 機構が供託等 |
| 向き | **初回はこれ** | 話がまとまっている相手がいる場合 | 相続未登記・所在不明 |

### ①農地バンク（農地中間管理機構）経由 — 推奨

1. 借受希望者として機構に登録
2. 機構が地主から農地を借り受ける
3. 機構が**促進計画**を作成 → 都道府県知事が認可・公告 → 権利が発生
4. 機構からあなたへ転貸

利点:
- 地主は「知らない個人」ではなく公的機関に貸す形になるので同意を得やすい
- 賃料の集金・支払いを機構が行う。滞納リスクの話をしなくて済む
- 期間満了で確実に戻る（農地法の法定更新が働かない）ため、地主が安心する
- **地域計画（目標地図）**に位置づけられれば、以後の集積が進めやすい

注意:
- 機構は地域計画に沿ってしか動かない。目標地図に載る努力が本体

### ②農地法3条許可

当事者間で賃貸借・使用貸借・売買を行い、農業委員会の許可を得る。
**2023年4月1日に下限面積要件（都府県50a／北海道2ha）は廃止された**ので、
小面積から始められる。ただし他の要件は残る:

- [ ] **全部効率利用要件** — 取得後に所有・借入する農地の**すべて**を効率的に利用すること
      （＝既に荒らしている農地があるとここで止まる）
- [ ] **農作業常時従事要件** — 原則年間150日以上の農作業従事（法人は別要件）
- [ ] **地域調和要件** — 周辺の農地利用に支障を及ぼさないこと
      → **自然栽培はここで論点になる。** 「草を放置して隣に種が飛ぶ」「病害虫の発生源になる」
        という懸念が出る。畦畔・法面の草刈り計画、緩衝帯、病害虫の観察記録を
        あらかじめ書面で示す（`templates/自然栽培_転換計画書.md`）
- [ ] 法人の場合は**農地所有適格法人**の要件（所有する場合）。賃借なら一般法人でも可能だが
      解除条件付き契約・地域との適切な役割分担・業務執行役員等1名以上の常時従事が要る

### ③所有者不明農地の利用権設定

`03` の末尾のとおり、農業委員会の探索 → 公示2か月 → 機構への通知 →
知事の裁定 → 公告で、機構に**最長40年**の利用権が設定される。
平成30年11月創設、令和4年改正で期間が延長された。

荒廃農地の多くは相続未登記であり、**このルートを知っているかどうかで
使える農地の母数が数倍変わる。** 農業委員会に「この制度で進められないか」と
明示的に尋ねること。委員会側も手続の手間から積極的でない場合があるので、
借り手が具体的な営農計画を持って申し出ることが実質的な起動条件になる。

## 契約条件の詰め方

荒廃農地の再生は借り手が費用を負担するのが通例。だからこそ条件を先に文書化する。

| 項目 | 推奨 | 理由 |
|---|---|---|
| 期間 | **10年以上**（機構経由なら長期が取りやすい） | 自然栽培は3年間ほぼ無収入。5年では投資が回収できない |
| 賃料 | 荒廃農地は無償〜反あたり数千円／年 | 再生費用の負担と相殺する交渉ができる |
| 再生費用 | 借り手負担。ただし**原状回復義務を免除**してもらう | 再生して返すのに「元の藪に戻せ」は不合理 |
| 中途解約 | 予告期間を長く（1作以上） | 多年生作物の茶は特に回収期間が長い |
| 栽培方法 | **無農薬・無化学肥料で行うことを契約書に明記** | 後から「農薬を撒け」と言われないため。有機JASの継続性の証明にもなる |
| 更新 | 更新の協議条項 | 期間満了で土地が戻る前提の機構契約では特に重要 |
| 境界・法面 | 管理範囲を図面で特定 | 法面の草刈り負担は面積の数字に出ない |
| 水利 | 水利費の負担者、取水の可否 | 集落の水利組合の承認が別途要る |

## タイムライン管理

権利が発生する日（許可日／公告日）より前に作業を始めない。
ただし**地主の承諾を得た上での事前の現地確認・草刈り**は、地域での信用構築として有効。
「許可が出る前に勝手に重機を入れた」は最悪の始め方になる。
